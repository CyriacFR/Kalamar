# Getting help

Kalamar is maintained by volunteers in their free time. There is no private support, no Discussions board and no
guaranteed answer.

- **Read first**: [docs/getting-started.md](docs/getting-started.md) (installing, playing, what to do when a step
  fails) and the [documentation index](docs/README.md). The documentation is the reference.
- **A bug or an idea**: an issue, with the bug report or feature request form, which says what to attach. Search the
  open issues first.
- **A change you wrote**: a pull request ([CONTRIBUTING.md](CONTRIBUTING.md)).
- **A security problem**: privately, as [SECURITY.md](SECURITY.md) explains; never in a public issue.
- **A community server** (accounts, bans, rules, a match result): that server's operator, whose contact the launcher
  shows on the server's page. This project runs no server.
- **Running or writing a server**: the server repository,
  [kalamar-server](https://github.com/CyriacFR/kalamar-server), its README and `docs/operator-first-steps.md`.

No help is given, here or in any channel of the project, to obtain the game, its update, keys or firmware, and links
to such files are removed. Kalamar works only with your own copy of the game, dumped from your own console.
